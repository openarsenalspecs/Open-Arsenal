# Large Language Model Specifications

The Open Arsenal Large Language Model (LLM) Directory brings together a diverse collection of open-source specifications incorporating large language model technology into modular AI architectures, software platforms, and specialized applications. These specifications explore the many ways LLMs can be integrated and applied, including natural language processing, intelligent reasoning, model orchestration, provider interoperability, automation, contextual analysis, translation, content optimization, and knowledge-driven systems. From native and locally hosted models to cloud-based AI services and multi-provider integrations, the collection demonstrates the flexibility of LLM technology across industries and technological environments.

The directory also highlights the supporting infrastructure needed to make large language models more efficient, reliable, secure, and transparent. Its areas of focus include model evaluation and verification, privacy-preserving processing, secure AI execution, regulatory compliance, intelligent caching, semantic optimization, controlled information retrieval, and explainable AI interactions. By bringing these capabilities together through modular, extensible specifications, Open Arsenal promotes an interoperable approach to LLM development and integration that supports innovation, user control, deployment flexibility, and the continued advancement of the open-source AI ecosystem.

- **Aurelia Civic OS**  
  [https://roxanneardary.com/aurelia-civic-os/](https://roxanneardary.com/aurelia-civic-os/)  
  Aurelia Civic OS is a municipal-first civic operating system that coordinates real-world labor, services, and manufacturing through structured intent, verified skill networks, and locality-based execution. Its AI Interface Layer (LLM Gateway) uses the LLM only for intent parsing into structured queries, explanation of routing decisions, and the user interaction layer.

- **BranchWeb**  
  [https://roxanneardary.com/branchweb/](https://roxanneardary.com/branchweb/)  
  BranchWeb turns your GitHub or GitLab repositories into stunning interactive visual trees with AI-generated images, dynamic visualizations, and deployable websites. Its AI Provider Plugins include a Large Language Models section covering local LLMs, OpenAI-compatible APIs, Ollama, llama.cpp, Hugging Face, and enterprise AI providers.

- **Cognitive Orchestration Stack (COS)**  
  [https://roxanneardary.com/cognitive-orchestration-stack/](https://roxanneardary.com/cognitive-orchestration-stack/)  
  Cognitive Orchestration Stack (COS) is an open-source modular AI infrastructure framework that separates reasoning from generation using structured, schema-driven modules to improve efficiency, reduce compute waste, and enable scalable, transparent, and adaptive cognitive workflows. It separates large language model intelligence into modular components rather than treating LLMs as single, all-purpose reasoning engines.

  [https://roxanneardary.com/contextkernel/](https://roxanneardary.com/contextkernel/)  
  ContextKernel is a privacy-preserving, open-source AI for contextual threat detection, behavioral risk analysis, and secure alerts within encrypted communication environments. Its LLM Training and Fine-Tuning Module trains and fine-tunes language models for contextual safety and behavioral risk classification.

- **Corelia**

  Corelia is a sovereign open-source CMS with AI, end-to-end encryption, SEO and LLM optimization, website importing, and modular tools for secure digital publishing. Its AI Engine includes an LLM Manager alongside prompt libraries, AI agents, and AI search, with LLM optimization for page structure, citations, and semantic content.

- **Feedback Living Model**  
  [https://roxanneardary.com/feedback-living-model/](https://roxanneardary.com/feedback-living-model/)  
  Feedback Living Model (FLM) is a systemic intelligence framework that models markets as evolving feedback organisms, analyzing capital flows, structural dependencies, narratives, and feedback loops to simulate economic regimes, fragility, and cascade-driven instability. Its Scenario Generator (LLM Layer) generates structured systemic scenarios covering trigger events, cascade pathways, affected sectors, and amplification.

Its LLM Provider Plugins connect FinAxis to compatible AI models, including local LLMs, self-hosted models, and cloud-based providers.

- **Securekit**  
  [https://roxanneardary.com/securekit/](https://roxanneardary.com/securekit/)  
  Securekit is a protocol-agnostic security kernel that protects AI systems by enforcing zero-trust, sandboxed execution for all tool calls across MCP, OpenAI, and custom agent frameworks. It enforces zero-trust, sandboxed execution for AI tool calls across any LLM or agent system.

  [https://roxanneardary.com/semantic-firewall/](https://roxanneardary.com/semantic-firewall/)

Its LLM Gateway / Relay Layer is a zero-trust proxy API with multi-provider LLM support, and it sits between the user and any public or hosted AI system.

  [https://roxanneardary.com/singularity/](https://roxanneardary.com/singularity/)
